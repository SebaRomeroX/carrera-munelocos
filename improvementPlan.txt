P0 — BUGS Y CORRECCIONES DE JUEGO (lo más urgente)
====================================================================

[x] 1. HTML inválido: falta cerrar el span en index.html (línea ~24)  (HECHO 2026-10-21)
       `<span id="spanMensaje">` nunca se cierra antes de `</h2>`.
       -> Cerrar el span. Validar con https://validator.w3.org

[x] 2. Línea de meta injusta (carrera.js, función dibujar())  (HECHO 2026-10-21)
       El jugador necesita `ancho - unidad*1.6`, rival1 `ancho - unidad*1.2`,
       rival2 `ancho - unidad*1.8`. El jugador SIEMPRE corre más que los bots.
       -> Definir UNA constante META = anchoImagenFondo - unidad*1.2
          y usarla para los tres corredores.

[x] 3. Variables implícitas globales (rompe en "use strict" / módulos)  (HECHO 2026-10-21)
       Falta declarar: imagenIzquierda, imagenDerecha, intervalo,
       imagenRival1, imagenRival2.
       -> Agregar let/const a todas. Agregar "use strict" al inicio
          (o convertir a módulo ES: <script type="module">).

[x] 4. Acumulación de event listeners en #botonSiguiente  (HECHO 2026-10-22)
       mostrarMensajeIntro() agrega addEventListener('click', cuentaRegresiva)
       CADA vez que pasa por el mensaje 5, y 'determinarPersonaje' se agrega
       desde revisarEleccion() cada vez que se detecta una elección.
       -> Definar UN solo listener al inicio y despachar con una máquina
          de estados (ver item 10) en vez de agregar/quitar listeners.

[x] 5. validadcionInicio nunca se pone en false  (HECHO 2026-10-22)
       Después de victoria() se puede seguir moviendo al personaje
       (las posiciones ya se resetearon, así que el muñeco "camina"
       en la pantalla de resultado).
       -> Poner validadcionInicio=false dentro de victoria(),
          y también resetear pasoIzquierdo/pasoDerecho.

[x] 6. Balanza rota por niveles (imposible ~nivel 15)  (HECHO 2026-10-22)
       velocidadRival1 = aleatorio(120,130) - dificultad*0.1
       velocidadRival2 = 150 - dificultad          <- crece 10x más rápido
       Con dificultad += 10 por nivel, ambos llegan a <= 0 ms
       (setInterval lo clampa a 1ms → ganan siempre).
       -> Usar un modelo acotado, p. ej.:
          intervalo = Math.max(MIN_MS, BASE - nivel * DELTA)
          con MIN_MS ~ 45-60ms y DELTA distinto para cada rival,
          más un pequeño factor aleatorio (±5%) para que cada carrera
          se sienta distinta. Ver item 12 para mejor IA.

[x] 7. Detección de elección por polling  (HECHO 2026-10-22)
       setInterval(revisarEleccion, 50) cada 50ms consulta 5 inputs.
       -> Reemplazar por un listener 'change' en el contenedor #iconos
          (event delegation). Cero polling, código más corto.

[x] 8. Teclado: keyCode está deprecado y el listener es global  (HECHO 2026-10-22)
       correr() usa tecla.keyCode (deprecated) y está registrado en
       document aunque la carrera no esté activa.
       -> Usar e.key === 'ArrowLeft' / 'ArrowRight',
          y registrar el listener solo durante la carrera
          (o guardar un estado 'fase' y salir temprano).

[x] 9. Fondo/canvas pueden dibujarse antes de cargar las imágenes  (HECHO 2026-10-22)
       dibujar() se llama sin esperar a que imagenFondo cargue
       (primeros frames en blanco / personajes invisibles).
       -> Precargar todas las imágenes con Promise.all y solo entonces
          habilitar el botón "Comenzar". Mostrar un "Cargando..." simple.

[x] 10. Sin máquina de estados (causa raíz de 1, 4, 5, 8)  (HECHO 2026-10-22)
       El flujo se controla con contadorMensajes + addEventListener sueltos.
       -> Introducir una variable `fase`:
          'intro' | 'seleccion' | 'instrucciones' | 'cuenta' |
          'carrera' | 'resultado'
          Un único handler en el botón que hace switch(fase).
          Esto hace trivial agregar reinicio total, pausa, etc.

====================================================================
P1 — CALIDAD, PERFORMANCE Y ACCESIBILIDAD
====================================================================

[x] 11. Renderizar con requestAnimationFrame, no setInterval(dibujar, 50)  (HECHO 2026-10-23)
       setInterval a 50ms causa jank y gasta batería en móvil.
       -> loop con rAF + cálculo de movimiento con delta-time
          (los bots y el jugador se moverán igual de rápido en
          cualquier refresh rate, incluidas pantallas 120Hz).

[x] 12. Mejorar la IA de los bots  (HECHO 2026-10-23)
       Hoy: avance constante a intervalo fijo (predecible y plano).
       -> Darles "rachas": pausas ocasionales de 100-300ms y
          sprints. Mantener la velocidad media calculada para que
          el nivel se sienta retador pero siempre ganable.

[x] 13. Accesibilidad del selector de personajes  (HECHO 2026-10-23)
       `.radio{display:none}` hace los inputs NO enfocables con teclado
       ni leídos por lectores de pantalla de forma usable.
       -> Cambiar a .radio{ position:absolute; opacity:0 } (sigue focusable)
          + estilo de foco visible en .icono:has(input:focus-visible)
          + aria-label en cada label.

[x] 14. Canvas y botones accesibles  (HECHO 2026-10-23)
       -> canvas con aria-label / contenido fallback
          botones ◀ ▶ con aria-label="Paso izquierdo"/"Paso derecho"

[x] 15. Móvil: quitar el delay táctil en los botones de correr  (HECHO 2026-10-23)
       -> Agregar touch-action: manipulation y -webkit-tap-highlight-color:
          transparent a .btn-correr; considerar pointerdown en vez de
          touchstart (funciona igual en stylus/trackpad).

[x] 16. Layout: body con 98vw/98vh + margin provoca scrollbars  (HECHO 2026-10-23)
       por redondeo, y el footer fixed tapa contenido en pantallas chicas.
       -> Quitar width/height del body, usar min-height: 100dvh
          (dvh resuelve el salto de la barra de direcciones en iOS).
          Footer estático o con padding-bottom en el main.

[x] 17. CSS: reglas muertas y typos  (HECHO 2026-10-23)
       `.mensaje{...}` dentro del media query no existe la clase
       (el id es #mensaje). `.iconos{gap:60px}` duplicado.
       `max-width: 1204px` probablemente era 1200px.
       -> Limpiar. Agregar al menos un breakpoint intermedio (640px)
          ya que hoy solo hay min-width:1024px.

[x] 18. Optimizar assets (~1 MB ahorrable)  (HECHO 2026-10-24)
       - Borrar imágenes no referenciadas: rojo.png, azul.png, verde.png,
         rosa.png, amarillo.png (~1 MB en total, ninguna se usa).
       - fondo.png (776 KB) -> convertir a WebP/AVIF (~80-150 KB).
       - Los muñecos PNG de 120-240 KB -> WebP con transparencia.
       Repo hoy pesa 6.28 MiB en el pack de git; bajaría a < 2 MiB.

[x] 19. innerHTML -> textContent  (HECHO 2026-10-24)
       spanMensaje.innerHTML='3...' etc. Usar textContent
       (más rápido y sin riesgo si algún día se interpola input del usuario).

[x] 20. Sonido y feedback  (HECHO 2026-10-25)
       -> WebAudio API sin archivos: pasos (blip corto), cuenta regresiva,
          fanfarria de victoria. Con toggle de mute persistido.

[x] 21. prefers-reduced-motion  (HECHO 2026-10-25)
       -> Respetar la media query: desactivar animaciones de cabeceo
          y la transición de carga del body.
